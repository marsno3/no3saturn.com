Lux Z

visual art, machine learning, DNA

This project explores how biological information can be translated into visual form through generative AI.

Vibrio fischeri is a bioluminescent marine bacterium that glows when a population reaches a certain density. Using its genomic data, I developed a computational pipeline that transforms DNA sequences into images and animations generated with Stable Diffusion.

Instead of using biology as a metaphor or visual inspiration, the project treats genomic data as a set of instructions for image generation. Properties of DNA and proteins are translated into parameters that shape colour, brightness, and composition, allowing each gene to generate its own visual identity. Alongside the natural genes, I also introduced a synthetic gene, LuxZ, placing an artificial sequence on equal footing with the biological ones.
